# Схемы и виды платы FCPLCn

Эти файлы экспортированы непосредственно из текущих исходников KiCad 10.
Принципиальные схемы содержат полный лист; SVG и PDF позволяют увеличить любой
узел без потери качества. PNG предназначены для предварительного просмотра в README.

| Документ                             | Предпросмотр               | Векторная версия           | PDF                        |
| ------------------------------------ | -------------------------- | -------------------------- | -------------------------- |
| Верхняя плата CPU                    | [PNG](cpu-schematic.png)   | [SVG](cpu-schematic.svg)   | [PDF](cpu-schematic.pdf)   |
| Нижняя плата реле и входов           | [PNG](relay-schematic.png) | [SVG](relay-schematic.svg) | [PDF](relay-schematic.pdf) |
| CPU, верхний слой меди и шелкография | [PNG](cpu-pcb.png)         | [SVG](cpu-pcb.svg)         | —                          |
| CPU, нижний слой меди и шелкография  | [PNG](cpu-pcb-bottom.png)  | [SVG](cpu-pcb-bottom.svg)  | —                          |

На нижнем виде CPU включено зеркальное отображение: показан взгляд со стороны
нижних компонентов. Виды платы имеют тёмный фон для читаемости шелкографии;
геометрия взята непосредственно из KiCad. Эти иллюстрации помогают читать расположение цепей;
для производства используются исходники KiCad и подготовленные производственные файлы.

Пересоздать экспорты из корня репозитория:

```sh
./tools/export-readme-schematics.sh
```

Нужны KiCad CLI, Poppler (`pdftoppm`) и Python 3; для PNG платы —
`rsvg-convert` либо Swift/AppKit на macOS. Экспорт не изменяет схемы, разводку
или заливки. Версия KiCad, имена исходников и их SHA-256 сохранены в
[manifest.json](manifest.json).
