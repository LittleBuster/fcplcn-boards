# FCPLC-080806-3v1

Тестовое устройство предыдущей генерации для программной платформы **FCPLCn**
(**Future City PLC Next**).

[Открыть исправленную схему PDF](Schematic_FCPLC-080806-3v1.pdf).

## Исправление EEPROM U42

Исходный документ пользователя — `Schematic_FCPLC-3v1_2026-11-21.pdf`, пять листов.
В этой копии исправлен только узел **24LC512-I/SM U42** на первом листе CPU:

| Вывод U42 | Исправленное подключение     |
| --------- | ---------------------------- |
| 5 · SDA   | `I2C1_SDA`, ESP32 GPIO2      |
| 6 · SCL   | `I2C1_SCL`, ESP32 GPIO1      |
| 7 · WP    | Сеть `GND`, запись разрешена |

Подписи SDA/SCL были переставлены местами. У WP удалён знак NC и добавлено
подключение подписанной сетью `GND`. Питание VCC, развязывающий конденсатор,
остальные сигналы и четыре других листа сохранены. Под узлом добавлена датированная
пометка о коррекции.

Это векторное исправление предоставленного PDF. Исходного проекта EasyEDA/CAD
для этой модели в репозитории нет; печатная плата и производственные файлы здесь
не изменялись. На физическом тестовом устройстве подключения U42 необходимо сверить
с исправленной схемой.

## Профиль в прошивке

Технический ID — `fcplc-080806-3v1`. Профиль выбирает драйвер EEPROM **24LC512**
ёмкостью **64 КиБ**, а не FRAM текущего комплекта FCPLCN-161608-1v0.

Подробные подключения и выбор профиля описаны в
[документации программной части](https://github.com/LittleBuster/fcplcn-soft/blob/main/docs/hardware/FCPLC-080806-3v1.md).
